## 2026-08-02 addendum — annotated webcam preview

ROADMAP.md's M13 deliverables list an "Optional debug preview"; this addendum adds it, on the alpha branch, per an explicit implementation task.

### Scope delivered

- `UIConfig.webcam_preview_enabled` (`config.py`) plus bounded `webcam_preview_jpeg_quality`/`webcam_preview_max_fps`/`webcam_preview_max_width` fields, all disabled/conservative by default. Only `config/jetson-full.yaml` turns the feature on; `config/default.yaml`, `config/continuous.yaml`, and `config/jetson-webcam.yaml` all gained the same block set to `false`/defaults, unchanged in effect.
- `PipelineWorker` (`api/worker.py`): per-tracked-face preview-label classification (`known`/`unknown`/`liveness_failed`) built from the same recognition decision, candidate, and liveness result the pipeline already computes -- no new recognition logic. Text is sanitized (printable-only, length-bounded) before being drawn. Drawing happens with OpenCV (`cv2.rectangle`/`cv2.putText`) on `frame.image.copy()`, never the source frame; the frame is optionally downscaled to `webcam_preview_max_width` and JPEG-encoded at `webcam_preview_jpeg_quality`, rate-limited to `webcam_preview_max_fps`. The result replaces a single `bytes` slot under the worker's existing lock (`latest_preview_jpeg()`); `stop()` clears it.
- `GET /api/v1/preview/latest.jpg` (`api/routes.py`): reuses `require_auth` (bearer header only, no URL/query token); returns `image/jpeg` with `Cache-Control: no-store, no-cache, must-revalidate`; maps disabled config to 404, no/non-running worker to 409, and "no frame yet" to 503 (see the route's own docstring for the exact reasoning).
- `ui/dashboard.html`: a preview `<img>` polled every 600 ms via `fetch(..., {headers: authHeaders(), cache: 'no-store'})`, using and revoking `URL.createObjectURL` object URLs, guarded against overlapping requests, started from `refreshAll()` (Connect/Refresh), and stopped on `visibilitychange`/`beforeunload`. No bearer token is stored anywhere beyond the existing in-page input field.
- Documentation: `HERMES.md` (M13 section), `ARCHITECTURE.md` (§4.8/§4.9/§13), `docs/THREAT_MODEL.md` (new assets bullet, two new threat rows, an M13 invariants section), `docs/RUNBOOK.md`, `docs/RUNNING_ON_JETSON.md` §9, and every touched config file's comments.

### Explicit exclusions

No recognition, enrollment, or active-user logic was added or changed; the preview only reads state the pipeline already produces. No new automated test was added or run, and no existing test was modified, per explicit owner instruction for this task.
