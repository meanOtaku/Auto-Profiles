Face Profile Dashboard

This page is a plain API client: every action below calls the versioned /api/v1 REST API directly. It contains no recognition, profile, enrollment, or active-user decision logic of its own (HERMES.md's UI rule). Closing this page has no effect on the running service.

Webcam preview

A server-drawn, bounded-rate snapshot (boxes and labels only, never a raw stream) polled from /api/v1/preview/latest.jpg. Only appears when this deployment's configuration enables it; this page draws nothing itself.
