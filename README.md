# Face Profile Recognition System — Documentation Pack

This folder contains the specification and engineering guidance for a headless-first facial recognition and profile personalization project.

## Files

- `HERMES.md` — Primary instructions for the AI coding agent
- `ARCHITECTURE.md` — Components, boundaries, data flow, and runtime design
- `CONTRIBUTING.md` — Development and review workflow
- `CODING_STANDARDS.md` — Python and architecture conventions
- `TESTING.md` — Test strategy, scenarios, and quality gates
- `ROADMAP.md` — Milestones, phases, and release targets

## How to Use

1. Copy all files to the repository root.
2. Point the AI coding agent to `HERMES.md` first.
3. Assign exactly one milestone at a time.
4. Require the agent to read all documentation before coding.
5. Do not accept a milestone without test evidence and manual verification notes.

## Recommended First Agent Prompt

```text
Read HERMES.md, ARCHITECTURE.md, CONTRIBUTING.md,
CODING_STANDARDS.md, TESTING.md, and ROADMAP.md.

Implement Milestone M0 only.
Do not implement later milestones.
Run all required checks and provide an exact milestone report.
```
